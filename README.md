# pH Scale

A simple pH Scale created using **HTML5 and CSS3**.

## 📌 About

This project displays the pH scale from **0 to 14**, using different colors to represent acidic, neutral, and alkaline levels.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox

## ✨ Features

* pH levels from 0.0 to 14.0
* Color-coded pH levels
* Acidic, Neutral, and Alkaline labels
* Centered vertical layout
* Simple and clean design

## 📱 Responsive Design

The project uses a fixed width for the pH bars and is currently designed as a basic CSS practice project.

## 🎯 Purpose

This project was created to practice:

* HTML structure
* CSS classes
* Flexbox
* Colors
* Spacing
* Text alignment
* Basic layout styling
